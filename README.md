## 📌 Featured Projects

### 📡 Cellular Traffic Prediction & RCA Agent — Ericsson Mentorship

An AI-driven framework for **short-term cellular traffic prediction** using serving-cell and neighboring-cell telemetry, paired with proactive network mitigation and an **AI-powered Root Cause Analysis (RCA) agent** that accelerates incident resolution and helps prevent recurring network issues.

**Tech:** GenAI, Agentic AI, RAN, Time Series, Fault Detection

---

### 🌾 AgriTwin: Field-to-Diagnosis Pipeline — Crop Disease System

An end-to-end crop disease system built on a **CNN-based leaf disease classifier** trained on multi-crop datasets. A **severity-scoring module** uses image segmentation to quantify affected leaf area, combined with confidence calibration.

A **Vision-Language/LLM explanation layer** converts raw predictions into plain-language diagnosis and treatment recommendations for farmers. The pipeline is deployed as a **FastAPI inference service** consumed by a companion mobile app for real-time, geo-tagged field diagnostics.

**Tech:** Python, PyTorch, Computer Vision, CNNs, Image Segmentation, VLM/LLM Integration, FastAPI, React Native

---

### 🚁 Drone Autonomous Vision System — ICMTC

A real-time computer vision system for drone object detection and tracking, with an optimized deep learning model deployed on **Raspberry Pi** and a **multi-threaded pipeline** for efficient real-time performance.

**Tech:** Python, OpenCV, Deep Learning, YOLO, Raspberry Pi, Embedded AI

---

### 🧠 Mental Health Diagnostics — EEG Multi-Model AI

A multi-model AI system that analyzes **EEG signals** for ADHD, Epilepsy, Autism, and Schizophrenia simultaneously. It generates comprehensive textual reports correlating patient history with AI findings, backed by a secure, trackable database of diagnoses and clinical notes.

**Tech:** Python, Deep Learning, CNNs, EEG Signals, Flask

---

### 🚗 Car Damage Cost Estimator

An end-to-end **Generative AI and Computer Vision** pipeline that accelerates car-damage detection and severity estimation from days to seconds. Users upload images through the UI, the model classifies severity, and the app displays visual output plus a summary report that can be downloaded or integrated into insurer systems.

**Tech:** Python, Deep Learning, GenAI, RAG, Computer Vision, Streamlit

---

### 💊 Pharmaceutical Company Database

A relational database and secure web application that optimizes inventory tracking and data management for a pharmaceutical infrastructure.

**Tech:** SQL, C, Bootstrap, HTML, CSS, ASP.NET
